# HIGH NOTES V2.1 original assets

These assets were generated with the built-in ImageGen workflow from original HIGH NOTES prompts, then chroma-keyed, cropped, resized, and optimized locally. They contain no third-party characters, logos, stage designs, or text.

- `Sprites/UI/Adventure Items/adventure-items-sheet.png`: 5×4 item/equipment atlas used by Brad's shop and the backpack.
- `assets/sprites/runtime/hero-customization-overlays.png`: four transparent hair/head overlays used by the shared character runtime.
- `assets/arena/mossvale-amphitheatre-{background,midground,foreground}.webp`: layered Stock Battle stage art.
- `Sprites/Effects/arena-effects-sheet.png`: hit, guard, perfect-guard, dodge, projectile, ultimate, KO, and respawn effects.

Non-destructive generation masters are retained under `assets/masters/v2.1/`. Runtime code references only the optimized files above. Item/effect ordering is defined by the adjacent JSON manifests.
