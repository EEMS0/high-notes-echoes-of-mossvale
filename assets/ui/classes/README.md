# Starter-class icon assets

These four original icons were generated for HIGH NOTES' schema-23 starter-class selector and campaign HUD.

## Source and processing

- Lossless master: `../../masters/classes/high-notes-starter-class-atlas-v1.png`
- Runtime manifest: `manifest.json`
- Runtime exports: four 256 × 256 transparent WebP files in this directory
- Generator: OpenAI ImageGen, 14 August 2026

The generation prompt requested a strict 2 × 2 atlas of original, text-free musical-fantasy pixel-art emblems on transparent backgrounds: a gold pick-blade with teal soundwave for Riffblade, an amber moss-root shield for Groveguard, a cyan orb with violet echo crescents for Echo Weaver, and a rose winged beat with a sky-blue trail for Tempo Runner. It explicitly excluded characters, logos, typography, Nintendo imagery, and recognizable third-party class symbols.

The generated master is retained unchanged. Each cell was cropped, alpha-checked, resized, and exported separately for efficient browser loading. Only the optimized files are in the runtime manifest.
